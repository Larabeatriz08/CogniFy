# CogniFy

CogniFy é uma plataforma web inteligente desenvolvida para auxiliar na produtividade, organização e otimização dos estudos utilizando inteligência artificial.

O projeto foi inspirado em plataformas SaaS e aplicações modernas de tecnologia educacional, priorizando uma interface intuitiva, responsiva e uma experiência de usuário agradável.



## Sobre o Projeto

Além da landing page, a aplicação possui:

- Sistema de login
- Sistema de cadastro
- Integração com Supabase
- Autenticação de usuários
- Dashboard moderna e interativa
- Interface com identidade visual personalizada

O principal objetivo do projeto é demonstrar conhecimentos em desenvolvimento front-end moderno, UI/UX, autenticação de usuários e integração com banco de dados.
